## 3 · New (3½ min)
**Actors: z c s — the buzz sounds**

z = “ds”, c = “ts”, s = “s”. Tongue tip flat behind the upper teeth (not curled). Contrast them with yesterday’s zh ch sh.
- Actor **z-** (zài 在): like “ds” in “kids”. Cast: Zorro
- Actor **c-** (cài 菜): like “ts” in “cats” with a puff of air. Cast: Cinderella
- Actor **s-** (sān 三): as in English. Cast: Superman
- Set **-ia** (jiā 家): “yah”. Location: a zoo
- Set **-ie** (xiè 谢): “yeh”. Location: a movie theater
- Set **-iao** (xiǎo 小): “yow”. Location: a beach house
- Set **-iu** (liù 六): “yoh” (really i-ou). Location: a museum

**Task:** Cast z c s. Add four i-sets: ia ie iao iu.
