# Localised store listings — drafts

Play ranks each language's listing on its own text, so a localised title and short description
is the cheapest reach we can buy. These are **drafts written by hand, not machine-translated**,
in the order the ranking plan (`PLAY_STORE.md` → section 8) recommends; each needs one native
read-through before it goes into Play Console → Store presence → Main store listing → *Add
translation*. Character limits are Play's: title 30, short description 80. Counts were measured on
the exact strings (Unicode code points). Keep "HSK-aligned" wording; never "official HSK".

Screenshots carry English captions; add the translated caption pairs from the table at the end of
each section to `tools/icons.js` when a language is switched on.
